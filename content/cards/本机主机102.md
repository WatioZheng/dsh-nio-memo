# 本机主机（示例）

> 示例卡片 · v1 · 2026-10-10
> 场景：需要记录**本机硬件 / 网络 / 磁盘布局**等实况、且希望跨会话复用时命中本卡。
> ⚠️ 本卡为**通用示例**：主机名 / IP / 型号均为占位符，请替换为自己机器的实测值。

## 本机 = 示例主机

- **系统**：Linux（示例：Ubuntu 24.04 LTS 原生，非 WSL；PID 1 = systemd）
- **机型**：笔记本 / 台式机（可用 `dmidecode -s system-product-name` 查）
- **主机名**：`host-a`
- **网络**：
  - 局域网：`192.168.1.100`（**DHCP 动态，会变——别写死**；要固定须做 DHCP 保留 / 静态）
  - overlay：`192.168.192.100`（固定，跨机调用优先用它）
- **环境**：root 用户；Node v22 + Python 3.12
- **系统盘**：容量按实际填；LVM 结构示例——
  - `sda3` → VG `ubuntu-vg` → LV `ubuntu-lv`（ext4，挂载 `/`）
  - VG 预留空闲空间（备 LVM 快照 / 新 LV）
  - `/boot` 独立分区；swap 可用根分区上的 `/swap.img`

## 记录要点（写这类卡时值得记什么）

1. 主机名与机型（排查驱动 / 兼容性时用得上）
2. 局域网地址 + **是否 DHCP 动态**（写死会过时）
3. overlay / 内网固定地址（跨机调用用）
4. 磁盘与分区布局（扩容 / 备份前必看）
5. 已占用的端口与服务绑定方式
